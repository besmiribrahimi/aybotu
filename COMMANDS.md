## 👥 Member Commands

These commands are available to all server members.

| Command | Description |
|---------|-------------|
| `/ping` | Check the bot's latency and response time |
| `/userinfo` | Display detailed information about a user |
| `/leaderboard` | View the message activity leaderboard |
| `/mcall` | Call moderators to the admin chat channel |
| `/coinflip` | Flip a coin (heads or tails) |
| `/dice` | Roll a dice (1-6) |
| `/rps` | Play rock-paper-scissors with the bot |
| `/8ball` | Ask the magic 8-ball a question and get a mystical answer |
| `/help` | Display available commands |
| `/rules` | View server rules |
| `/ship` | Ship two users together (shows a compatibility rating) |
| `/shipr` | Random ship two members |
| `/banall` | Ban all users (emergency command) |
| `/secret` | Unlock a secret command or easter egg |

---

## 🛡️ Admin Commands

These commands are **restricted to users with Administrator permissions**.

| Command | Description |
|---------|-------------|
| `/ban` | Ban a member from the server with optional reason |
| `/kick` | Kick a member from the server |
| `/mute` | Timeout a member (temporary mute) |
| `/unmute` | Remove timeout from a member |
| `/warn` | Send a warning DM to a member |
| `/unban` | Unban a previously banned member |
| `/giverole` | Give a role to a member |
| `/removerole` | Remove a role from a member |
| `/vid` | Post a video embed to a channel |
| `/userd` | Delete user data |
| `/lsu` | Set or update the moderation logs channel |
| `/setupmcalls` | Set up the moderator call channel |
| `/setupremove` | Remove the moderator call channel |
| `/welcomeset` | Configure the welcome message channel |
| `/leaveset` | Configure the leave/goodbye message channel |
| `/bannedwords` | View and manage list of blocked words |

## ⚙️ Features

### Moderation System
- Full ban/kick/mute system with reason logging
- Automatic moderation logs channel
- Banned words filtering

### Engagement Features
- Message activity leaderboard tracking
- User profiling with `/userinfo`
- Fun commands like ship, 8ball, and games

### Setup Commands
- Customizable welcome/leave messages
- Moderator call system for quick admin access
- Moderation logs channel setup

### Game Commands
- Rock-paper-scissors
- Coin flip
- Dice roller
- Magic 8-ball
- User shipping feature

## 📝 Notes

- All commands use Discord's Slash Commands (`/`)
- Admin commands require **Administrator** permission
- Some commands may require specific channel setup (see admin setup commands)
- Check the `/help` command in-server for quick reference
